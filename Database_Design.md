# Database Design
The application uses a relational Database Management System (MySQL) to store the data systematically. Below is the detailed design of the backend tables used in the "Smart Hospital App".

## 1. Table : `users`
This table stores the information of all the users in the system, including Patients, Doctors, and Administrators.

| Field Name | Data Type | Size / Length | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| **id** | INT | - | PRIMARY KEY, AUTO_INCREMENT | Unique Identifier for each user |
| **name** | VARCHAR | 255 | NOT NULL | Full Name of the user |
| **age** | INT | - | - | Age of the user |
| **mobile** | VARCHAR | 20 | UNIQUE, NOT NULL | Primary login identifier & contact |
| **role** | VARCHAR | 50 | DEFAULT 'patient' | Type of user (patient, doctor, admin) |
| **department** | VARCHAR | 100 | - | Doctor's specialty department |
| **education** | VARCHAR | 100 | - | Doctor's qualification (MBBS, MD, etc.) |
| **status** | VARCHAR | 50 | DEFAULT 'Available' | Doctor's current availability |
| **queue_current** | INT | - | DEFAULT 0 | Currently treating patient queue number |
| **queue_total** | INT | - | DEFAULT 0 | Total patients in doctor's queue |
| **room_number** | VARCHAR | 50 | - | Doctor's cabin/ward number |
| **description** | TEXT | - | - | Short bio/description of doctor |
| **created_at** | TIMESTAMP | - | DEFAULT CURRENT_TIMESTAMP | Date and time of user registration |

---

## 2. Table : `appointments`
This table handles all the appointment bookings generated by the patients.

| Field Name | Data Type | Size / Length | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| **id** | INT | - | PRIMARY KEY, AUTO_INCREMENT | Unique Appointment Identifier |
| **dept** | VARCHAR | 100 | NOT NULL | Department for which booking is made |
| **doctor_name** | VARCHAR | 255 | - | Name of the assigned doctor |
| **date** | VARCHAR | 100 | NOT NULL | Date string of the appointment |
| **status** | VARCHAR | 50 | DEFAULT 'Pending' | Status (Pending, Scheduled, Completed) |
| **user_mobile** | VARCHAR | 20 | FOREIGN KEY (users.mobile) | ID mapping to booked patient |
| **patient_name** | VARCHAR | 255 | - | Name of patient visiting |
| **patient_age** | INT | - | - | Age of patient visiting |
| **report_id** | VARCHAR | 50 | - | Reference to the generated medical report |

---

## 3. Table : `reports`
This table stores the medical reports and prescriptions created by the doctors after an appointment.

| Field Name | Data Type | Size / Length | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| **id** | INT | - | PRIMARY KEY, AUTO_INCREMENT | Unique Report Identifier |
| **appointment_id**| INT | - | UNIQUE, NOT NULL | Links report to a specific appointment |
| **diagnosis** | TEXT | - | - | Patient's medical diagnosis |
| **medicines** | TEXT | - | - | Prescribed medicines/dosage |
| **notes** | TEXT | - | - | Any additional doctor notes |
| **file_path** | TEXT | - | - | Path to any uploaded report files |
| **symptoms** | TEXT | - | - | Patient's reported symptoms |
| **follow_up_date**| VARCHAR | 100 | - | Date for next recommended visit |
| **created_at** | TIMESTAMP | - | DEFAULT CURRENT_TIMESTAMP | Date and time report was created |

---

## 4. Table : `messages`
This table captures the inquiries submitted by users through the 'Contact Us' form.

| Field Name | Data Type | Size / Length | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| **id** | INT | - | PRIMARY KEY, AUTO_INCREMENT | Unique Message ID |
| **name** | VARCHAR | 255 | - | Sender's Name |
| **subject** | VARCHAR | 255 | - | Subject of inquiry |
| **message** | TEXT | - | - | Detailed message content |
| **created_at** | TIMESTAMP | - | DEFAULT CURRENT_TIMESTAMP | Time message was submitted |

---

## 5. Table : `system_settings`
This table stores global settings for the hospital system.

| Field Name | Data Type | Size / Length | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| **key** | VARCHAR | 100 | PRIMARY KEY | Setting Name (e.g., 'wait_time') |
| **value** | TEXT | - | - | Setting Value |
